# Reason codes of the anet hub: the register of every code ever published.
#
# A reason code is a stable public interface. Nodes match on the code, never
# on the sentence, so the meaning of a code never changes, a code is never
# renamed, and a code that has been published is never used again for another
# meaning. This file is edited by hand and deliberately; there is no
# regeneration. internal/wire3/codes_registry_test.go holds it against the
# reason table in reasons.go, and the documentation renders it as the Since
# column of the hub reason table.
#
# One line per code, sorted by code, fields separated by a tab:
#
#     code   since   status   [retired   [replacement]]
#
#   code         a hub reason code of the table in reasons.go.
#   since        the first hub version that emitted the code, in the form
#                major.minor.patch.
#   status       active: the table has an entry for the code.
#                retired: the table has no entry for it any more. The line
#                stays, so the name is never reused.
#   retired      for a retired code, the version that removed the entry.
#   replacement  for a retired code, optionally the code that took its place.
#
# A code that a node also emits under the same name and meaning is mirrored
# on purpose; the exceptions are listed in the documentation tool
# docs/_tools/check_code_collisions.py of the ANet repository.
